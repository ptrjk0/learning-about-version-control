# Learning About Version Control
Solving merge conflicts takes conscious effort, but I can do it!

What I like the most about version control is the fact that we can avoid work getting entangled with others even when work is being done 
simultaneously. 

What I find the most confusing about version control is how git suggests changing the rebase config settings when attempting to git pull with a conflict, since it gets really easy to change global settings by accident as well.
